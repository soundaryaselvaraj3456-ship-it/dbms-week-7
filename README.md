# E-Commerce Database Management System

## Description

This project uses SQL to manage and retrieve e-commerce data, including customers, products, orders, payments, categories, and reviews.

## Database

`EcommerceDB`

## Tables Used

* Customer
* Product
* Orders
* Payment
* Category
* Order_Details
* Review

## Operations Performed

* Retrieve customer, product, order, and payment details.
* Filter products based on price, category, and stock availability.
* Search customers by city and registration date.
* Join tables to retrieve customer orders and product details.
* Count total customers and orders.
* Analyze completed, pending, and cancelled orders.
* Identify top-priced products and popular products based on reviews.

## SQL Concepts Used

`SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `LIKE`, `BETWEEN`, `IN`, `JOIN`, `GROUP BY`, `COUNT()`, `AVG()`, `CASE`, and `LIMIT`.

## Conclusion

This project demonstrates how SQL helps manage e-commerce data, retrieve useful information, track orders, and analyze products and customer activity.
